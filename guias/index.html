Cómo arreglar los fallos de accesibilidad más comunes

Estas son las 30 reglas de las pautas WCAG 2.2 que más fallan en las webs que analizamos. Cada guía explica qué significa, a quién perjudica y cómo se arregla, con un ejemplo de código.

Color y contraste

  • Contraste de color insuficiente en el texto
  • Enlaces que solo se distinguen por el color

Imágenes y textos alternativos

  • Imágenes sin texto alternativo (atributo alt)
  • Páginas sin título (etiqueta title)
  • Iframes sin título
  • Iconos SVG sin texto alternativo
  • Elementos role="img" sin texto alternativo
  • Vídeos sin subtítulos

Botones, enlaces y controles

  • Enlaces sin texto, como los iconos sin nombre
  • Botones sin texto o sin nombre accesible
  • Botones input sin texto (atributo value)
  • Elementos con aria-hidden que reciben el foco

Formularios

  • Campos de formulario sin etiqueta
  • Desplegables (select) sin etiqueta
  • Valores de autocomplete no válidos en formularios

Idioma

  • Página sin el atributo lang
  • Atributo lang con un idioma no válido
  • Textos en otro idioma con un lang no válido

Estructura de la página

  • Listas ul u ol con elementos que no son li
  • Elementos li fuera de una lista

Móvil, zum y tamaño

  • Zum bloqueado en el móvil (user-scalable=no)
  • Botones e iconos demasiado pequeños para pulsar

Teclado

  • Botones o enlaces dentro de otros
  • Zonas con scroll que no se pueden usar con el teclado
  • Falta el enlace para saltar al contenido

ARIA

  • Atributos ARIA no permitidos en un elemento
  • Atributos ARIA con valores no válidos
  • Roles ARIA sin sus atributos obligatorios
  • Roles ARIA que no existen

Otros

  • El nombre accesible no coincide con el texto visible
