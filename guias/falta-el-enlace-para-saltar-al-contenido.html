Falta el enlace para saltar al contenido: cómo arreglarlo

Las páginas deben tener medios para saltarse bloques repetidos. Garantiza que cada página tiene al menos un medio para que un usuario pueda saltarse la navegación y pasar directamente al contenido.

Pautas WCAG 2.2, nivel A · 2.4.1 Evitar bloques · regla de axe-core «bypass»

A quién perjudica

A quien navega solo con el teclado, con un pulsador o con un lector de pantalla: no llega a esa parte de la página o se queda atascado.

Cómo arreglarlo

  1. Añade al principio un enlace «Saltar al contenido» o marca la zona principal con main, para no tener que recorrer todo el menú con el teclado.

Ejemplo

<a class="saltar" href="#contenido">Saltar al contenido</a>
…
<main id="contenido">…</main>
