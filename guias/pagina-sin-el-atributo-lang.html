Página sin el atributo lang: cómo arreglarlo

El elemento <html> debe tener un atributo lang. Garantiza que cada documento HTML tiene un atributo lang.

Pautas WCAG 2.2, nivel A · 3.1.1 Idioma de la página · regla de axe-core «html-has-lang»

A quién perjudica

A quien usa un lector de pantalla: sin el idioma bien indicado, la voz lee el texto con la pronunciación de otro idioma y no se entiende.

Cómo arreglarlo

  1. Indica el idioma de la página en la etiqueta html, para que el lector de pantalla pronuncie bien el texto.

Ejemplo

<html lang="es">
